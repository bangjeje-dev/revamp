# BANGJEJE.DEV - Custom CMS & Template Portal

Folder ini dikhususkan untuk sistem Content Management System (CMS) dan Portal Unduhan.

## Fitur Utama

### 1. Manajemen Konten (Articles & Case Studies)
- Sistem untuk mengelola (membuat, memperbarui, dan menayangkan) artikel wawasan (Insights/Articles).
- Sistem untuk mempublikasikan portofolio dan studi kasus terbaru (Case Studies) secara dinamis.

### 2. Portal Download Template Website
- Direktori bagi user/pengunjung untuk melihat dan mengunduh (*download*) template website eksklusif buatan bangjeje.dev.
- Pengelolaan daftar template, preview, dan tautan unduh.
